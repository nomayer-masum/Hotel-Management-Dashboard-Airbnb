# Hotel Management Dashboard Analysis

## Overview
This Dashboard provides an analysis of the Hotel Management Dashboard for Airbnb, focusing on key performance metrics such as revenue trends, cancellation rates, booking ratios, and distribution across channels and locations. The analysis is based on data extracted from the provided dashboard image.

- **Tool Used:** Microsoft Excel
